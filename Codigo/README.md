# Eletro Rádio Esperança – Chatbot e Painel de Gestão

Sistema desenvolvido para a Eletro Rádio Esperança, composto por um chatbot de atendimento via Telegram e um painel de gestão para uso interno da loja.

## Estrutura do Projeto

- `backend/`: API, integração com Telegram e regras de negócio.
- `frontend/`: painel de gestão desenvolvido em React.
- `database/`: scripts SQL para criação e configuração do banco PostgreSQL.
