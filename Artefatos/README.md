# Artefatos do Projeto

Este diretório reúne todos os artefatos produzidos durante o desenvolvimento do sistema **Chatbot de Atendimento da Eletro Rádio Esperança**, incluindo modelos UML, diagramas estruturais e comportamentais, protótipos e documentos auxiliares.

Os artefatos aqui organizados complementam a documentação oficial (Documento de Visão, Documento de Viabilidade e Documentação de Projeto), garantindo rastreabilidade entre requisitos, arquitetura e implementação.


## 📁 Estrutura do Diretório e Descrição dos Artefatos

A seguir estão listados os artefatos presentes neste diretório, acompanhados de uma breve descrição de seu conteúdo e finalidade.

### 1. **Diagramas de Comunicação**
Contém os diagramas de comunicação derivados dos Diagramas de Sequência, representando a troca de mensagens entre os principais componentes do sistema.

### 2. **Diagramas de Classes**
Inclui os diagramas estruturais do sistema, tanto na visão geral por pacotes quanto na visão de entidades de domínio, serviços conversacionais e módulos administrativos.

### 3. **Diagramas de Sequência do Sistema**
Apresenta os fluxos dinâmicos referentes aos casos de uso UC01–UC10, demonstrando a interação entre WhatsApp, Chatbot, Backend, Plataforma de Atendimento e módulos internos.

### 4. **Telas**
Reúne os protótipos de interface do painel administrativo e dos fluxos conversacionais no WhatsApp, conforme descrito na seção de Projeto de Interface.

### 5. **CasodeUso.png**
Representação visual consolidada do Diagrama de Casos de Uso do sistema.

### 6. **DiagramaArquitetura.png**
Modelo de arquitetura lógica (C4 simplificado), evidenciando camadas, componentes e integrações externas (WhatsApp Cloud API, Backend, Supabase).

### 7. **DiagramaEstados.png**
Diagrama de Estados que descreve o ciclo de vida de uma conversa no chatbot, desde a primeira mensagem até o encerramento.

### 8. **ModeloDeDados.png**
DER (Diagrama Entidade-Relacionamento) contendo entidades, atributos principais e relacionamentos armazenados no banco Postgres/Supabase.

### 9. **Projeto-PreBanca_Atividade_A6.pdf**
Documento apresentado na pré-banca contendo resumo técnico, requisitos, artefatos e elementos de arquitetura.
